# 水下目标跟踪系统（K-Means + HSV + CSRT）

基于 **K-Means 优化 HSV 分割**与**动态 CSRT 跟踪器**的复杂环境自适应水下目标跟踪系统，提供 PyQt5 图形化操作界面。

系统针对水下环境光照不均、目标颜色多变、复杂背景干扰等问题，通过 K-Means 聚类自动提取目标 HSV 颜色阈值、动态调整亮度阈值下限、形态学处理与轮廓过滤相结合，实现对水下鱼类的稳定检测与持续跟踪，并支持实时计数、轨迹记录与结果视频导出。

## ✨ 功能特性

- **K-Means 自动阈值提取**：对选定区域进行 K-Means 聚类，自动计算目标 HSV 颜色范围，无需手动调参
- **动态阈值自适应**：根据帧平均亮度动态调整 V 值下限，暗帧/亮帧自动补偿，适应复杂光照
- **CSRT 目标跟踪**：高精度判别相关滤波跟踪器，抗遮挡、抗背景干扰
- **HSV 调参工具**：内置可视化调参面板，实时预览分割效果，可保存调参结果
- **多鱼类类型配置**：内置红鱼 / 蓝鱼 / 绿鱼 / 自定义鱼 4 类 HSV 配置，支持多阈值组合
- **形态学优化**：开闭运算去除噪点，轮廓宽高比过滤异常形状
- **图形界面**：PyQt5 桌面程序，支持视频选择、参数配置、实时预览、日志输出、进度显示
- **统计与导出**：鱼类数量统计、FPS 显示、跟踪轨迹 CSV 记录、结果视频保存

## 🚀 快速开始

### 1. 环境要求

- Python 3.8+
- 依赖：OpenCV、NumPy、scikit-learn、PyQt5

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 运行

```bash
python main.py
```

启动后通过界面操作：

1. **选择视频**：点击「选择视频」加载水下视频文件
2. **选择鱼种**：切换红鱼 / 蓝鱼 / 绿鱼 / 自定义鱼（自动载入对应 HSV 阈值）
3. **自动提取阈值**：点击「K-Means 自动提取」，框选目标区域自动计算 HSV 范围
4. **开始跟踪**：点击「开始跟踪」，实时显示检测框与计数，可随时停止
5. **调参**：点击「HSV 调参工具」打开调参面板，实时预览分割效果并保存配置

### 4. 配置文件说明（fish_config.json）

| 配置项 | 说明 |
|--------|------|
| `fish_types` | 各类鱼的 HSV 阈值（h/s/v 上下限） |
| `min_contour_area` | 最小轮廓面积（过滤小噪点） |
| `tracker_type` | 跟踪器类型（默认 CSRT） |
| `dynamic_threshold` | 是否启用动态亮度阈值 |
| `morphology_kernel` | 形态学核大小 |
| `contour_aspect_ratio` | 轮廓宽高比过滤范围 |
| `multi_hsv` | 是否启用多 HSV 阈值组合（红色鱼分段场景） |

## ⚙️ 核心算法说明

| 模块 | 说明 |
|------|------|
| `get_fish_hsv_by_clustering` | K-Means 聚类（n_clusters=2）自动提取目标 HSV 中心与范围 |
| `get_dynamic_v_threshold` | 按帧平均亮度（<50 暗帧 / >200 亮帧）动态调整 V 阈值 |
| `detect_fish` | HSV 阈值分割 + 形态学开闭 + 面积/宽高比过滤 |
| `init_tracker` | 初始化 OpenCV 跟踪器（CSRT） |
| 轨迹记录 | 每帧记录目标中心点，导出 CSV |

## ⚠️ 注意事项

- 视频文件较大时建议使用分辨率适中的素材，避免界面卡顿
- 首次运行会自动生成默认 `fish_config.json`
- 自定义鱼需在调参工具中调整阈值后保存，或直接编辑配置文件
